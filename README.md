# 操作マニュアル自動作成 管理画面（デモ）

現場で撮影した操作動画から、手順書の下書きを自動で作り、動画に注釈を入れて仕上げる管理画面のデモです。

**デモを開く → https://ktamura-art.github.io/video-manual-studio-demo/**

## できること
- 動画をアップロードすると、画面の切り替わりで手順を分けて、手順ごとの写真を抜き出す
- 動画に注釈を入れる：矢印・四角・円・番号・ラベル・吹き出し・ぼかし・画像挿入。タイムライン上で表示時間を調整できる
- 手順を編集する：タイトル・作業内容・注意レベル・表記チェック
- 出力：注釈入りの手順書（印刷・HTML保存）、注釈入り動画の書き出し
- 出力フォーマットを自由に作れる：用紙（A4縦・横）、手順の列数・並び順（左→右／S字）、矢印、写真の位置、ヘッダー項目、載せる欄（仕様表・注意事項・工具・材料・関連帳票・改訂履歴・承認欄）と順番、見出しの言語（日本語／英語／中国語の併記）
  - 標準で3種類：標準（A4縦）、作業指導書（A4横・フロー型）、現場掲示用（写真大きめ）
- 多言語対応：日本語・英語・中国語・タイ語で要約・動画の注釈・手順書を切り替え／併記
- ステータス管理：下書き → レビュー → 承認 → 公開

## デモでの扱い
- 手順分割・注釈編集・書き出しは、ブラウザ内で実際に処理しています
- 公開ページ（GitHub Pages）では解析サーバーにつながらないため、サンプル動画に限り用意した文章を当てはめるデモ動作になります
- 既存の帳票（PDF・Excel）からフォーマットを自動で作る機能は未実装です
- 動画とマニュアルは、そのブラウザ内に保存されます（解析サーバーを使うときだけ、動画をこのPCのサーバーに送ります）
- サンプル動画は架空の設備（MC-200）を描いたアニメーションです

## 解析サーバー（テスト実装・このPCで動かす）
動画の音声を文字起こしし、Claude で手順書の下書きと英語・中国語・タイ語の訳を作ります。

| 処理 | 使うもの |
|---|---|
| 文字起こし | faster-whisper（このPC内で処理・無料） |
| 手順書の作成・翻訳 | Claude API（`claude-opus-5-5`） |
| サーバー | Python + FastAPI（`server/app.py`） |

### 起動のしかた
1. ffmpeg を入れる：`brew install ffmpeg`
2. `server/start.sh` を実行する（初回は必要なものを自動で入れ、`server/.env` を作ります）
3. `server/.env` の `ANTHROPIC_API_KEY=` に Claude API のキーを入れて、もう一度 `server/start.sh`
4. ブラウザで **http://localhost:8000** を開く（画面もこのサーバーから配信します）

「生成設定」と「動画アップロード」の画面に接続状態が出ます。1本ごとの Claude の費用は、解析の完了時と「文書情報・履歴」に記録されます。

### 設定（`server/.env`）
- `CLAUDE_MODEL`：使うモデル（既定 `claude-opus-5-5`）
- `CLAUDE_EFFORT`：考える深さ `low` / `medium` / `high`（既定 `medium`）
- `WHISPER_MODEL`：文字起こしのモデル `small`（既定）／`medium`／`large-v3-turbo`。大きいほど正確で遅い（初回にダウンロード）

## 構成

- 解析サーバー：`server/`（`app.py` / `start.sh` / `requirements.txt` / `.env.example`）
