# 操作マニュアル自動作成 管理画面（デモ）

現場で撮影した操作動画から、手順書の下書きを自動で作り、動画に注釈を入れて仕上げる管理画面のデモです。

**デモを開く → https://ktamura-art.github.io/video-manual-studio-demo/**

## できること
- 動画をアップロードすると、画面の切り替わりで手順を分けて、手順ごとの写真を抜き出す
- 動画に注釈を入れる：矢印・四角・円・番号・ラベル・吹き出し・ぼかし・画像挿入。タイムライン上で表示時間を調整できる
- 手順を編集する：タイトル・作業内容・注意レベル・表記チェック
- 出力：注釈入りの手順書（印刷・HTML保存）、注釈入り動画の書き出し
- 出力フォーマットを自由に作れる：用紙（A4縦・横）、手順の列数・並び順（左→右／S字）、矢印、写真の位置、ヘッダー項目、載せる欄（仕様表・注意事項・工具・材料・関連帳票・改訂履歴・承認欄）と順番、見出しの言語（日本語／英語／中国語の併記）
  - 標準で3種類：標準（A4縦）、作業指導書（A4横・フロー型）、現場掲示用（写真大きめ）
- ステータス管理：下書き → レビュー → 承認 → 公開

## デモでの扱い
- 手順分割・注釈編集・書き出しは、ブラウザ内で実際に処理しています
- 音声の文字起こしと手順文の生成は、本番で API に接続する想定です。デモではサンプル動画に限り、用意した文章を当てはめます
- 既存の帳票（PDF・Excel）からフォーマットを自動で作る機能と、本文の翻訳は未実装です（見出しの言語併記のみ対応）
- アップロードした動画は、そのブラウザ内にだけ保存されます（サーバーには送信しません）
- サンプル動画は架空の設備（MC-200）を描いたアニメーションです
